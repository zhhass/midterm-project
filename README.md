# Brass & Blade Barbershop – Booking Website

Midterm project: a multi-page responsive website for a barbershop where clients can see services, meet barbers and request a booking.

**Live site:** _add your GitHub Pages / Netlify link here_

## Pages
1. `index.html` – Home (hero, features, opening hours)
2. `services.html` – Services with price table
3. `barbers.html` – Barbers (CSS Grid cards)
4. `booking.html` – Booking form
5. `contact.html` – Contact info + feedback form

## Features
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `address`, `footer`), table with `caption`/`thead`/`tbody`, two forms
- Navigation bar on every page (Bootstrap navbar, collapses on mobile)
- CSS: classes, IDs, custom properties, Flexbox (features, hours), Grid (barbers), positioning (sticky header, absolute stripe and badges)
- Media queries at 992px (tablet) and 576px (mobile)
- Bootstrap 5 grid, utility classes (`py-5`, `text-center`, `mb-3`, `g-4`), buttons, form controls
